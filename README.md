# Karthikeya Utukuru Portfolio

This is a self-contained Framer-style portfolio prototype based on Karthikeya Utukuru's resume. It is built with plain HTML, CSS, and JavaScript so it can be previewed locally or recreated in Framer.

## Edit These First

- Add real projects when they are ready.
- Replace or refine `assets/karthikeya-hero-photo.jpg` if you want a different hero photo.
- Update the academic year/GPA if your resume changes.
- Add more links such as deployed projects, certificates, or LeetCode/HackerRank profiles.

## Framer Handoff Prompt

Use this prompt in Framer AI if you want to recreate the concept there:

```text
Design a personal portfolio for Karthikeya Utukuru, a Computer Science Engineering student specializing in Artificial Intelligence and Machine Learning.
Style: clean, warm, polished, motion-forward, student-professional, with strong typography and a nature-inspired personal theme.
Sections: sticky nav, large hero with portrait, AI/ML profile statement, focus-area cards, about story, education, certification, toolkit, and contact.
Mood: curious, disciplined, analytical, collaborative, grounded, growth-focused.
Colors: warm off-white background, deep green-black text, sage green, muted blue, terracotta, and gold accents.
Interactions: smooth scroll reveals, subtle parallax on hero image, hover states on nav/buttons/cards.
Keep the first viewport focused on the person and their value: "I build my foundation in code, data, and intelligent systems."
```

Open `index.html` in a browser to preview the site, or run:

```bash
node server.mjs
```

Then visit `http://127.0.0.1:4173`.
